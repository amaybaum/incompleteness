## 4. Q12: the scope limit for modified workflows

**The question.** The gate covers runs of the frozen splice. A modified workflow on another branch, or one that omits
`environment:`, is outside it.
- The enumeration detects such runs if they carry the pinned blob or the frozen names, up to the final capture before
  landing. After landing, nothing detects them.
- F1's output is public from `E`, and the landed record is immutable (`G13`).
- A local run of the public code is outside every measure.

**(a) Accept this as the reading of "must remain blocked, including after landing".**
- **For.** No set-up. A post-landing computation cannot change the round's landed result.
- **Against.** An unauthorized *execution* of a modified workflow stays possible after landing, by any account with
  write access, which is the owner or the session.

**(b) Add a measure outside the round.**
- **(b1) A ruleset restricting changes to `.github/workflows/**` on all branches.**
  - Rulesets work on this repository (HF-5: `guardrail` exists). Whether a file-path (push) rule is available for a
    user-owned public repository is unverified.
  - It would also constrain every other round's legitimate workflow edits, which would need a bypass.
  - Under E-ID (iii) the bypass is also the session's.
- **(b2) Require approval of fork pull-request workflows for all external contributors** (an Actions setting).
  - Its current value is unreadable from here (HF-3).
  - It closes only the non-collaborator route, which the enumeration already detects before landing.
- **(b3) A later monitoring round** that extends the enumeration past landing. This is detection only.

**What the record implies.**
- c.6726548830 decided that the two named landing gaps need "a technical solution". Both concerned the frozen splice,
  and the Environment closes them.
- Q12's residual is of a different class: modified code, which local runs show no repository measure can fully block.
- The record does not decide Q12.

**Coordinator's recommendation (not a decision).** (a), recorded as the owner's reading. Optionally (b2) as cheap
hardening that does not touch the round's design.
