**Lemma SD1 (single defect) [W].** Setting:
- `V = Herm(4)` with `<a, b> = tr(ab)`; ipW is 4× this, so dual cones agree;

Then `K(e) = (Q ∩ e^*) + ℝ₊e` is closed and self-dual.

*Proof.*
1. **Closed.** Since `e − β(I − 2ggᵀ) ⪰ 0`, `tr e ≥ 2β > 0`, so `−e ∉ Q`. A sum of closed cones `A + B` is closed when
   `A ∩ (−B) = {0}`; apply this to `(Q ∩ e^*) + ℝ₊e`.
2. **`K ⊆ K*`.** For `k = q + λe`, `k' = q' + λ'e`:
   `<k, k'> = <q,q'> + λ<e,q'> + λ'<q,e> + λλ'<e,e> ≥ 0`.
3. **The dual.** `K* = e^* ∩ (Q ∩ e^*)^* = e^* ∩ cl(Q + ℝ₊e) = e^* ∩ (Q + ℝ₊e)`. This uses `(A ∩ B)* = cl(A* + B*)`,
   `Q* = Q`, and the closedness from step 1.
4. **`K* ⊆ K` reduces to (GL).** Write `y ∈ K*` as `y = z + se` with `z ⪰ 0`, `s ≥ 0`, `<y,e> ≥ 0`.
   - If `<z,e> ≥ 0`, then `y ∈ K` directly.
   - Otherwise put `τ = −<z,e>/<e,e>`; then `s ≥ τ`.
   - (GL) says `z + τe ⪰ 0`. Since `<z + τe, e> = 0`, we get `y = (z + τe) + (s − τ)e ∈ K`.
5. **(GL) from a local lemma.** The local lemma: if `w ⪰ 0` and `<w,e> < 0`, then `w + εe ⪰ 0` for some `ε > 0`.
   Granting it, the set `{σ ≥ 0 : z + σe ⪰ 0}` is a closed interval `[0, σ_hi]`, bounded because `e ∉ Q`.
   - If `σ_hi < τ`, then `w = z + σ_hi e` is PSD with `<w,e> < 0`, yet it cannot move along `+e`. This contradicts
     the local lemma.
   - So `σ_hi ≥ τ`, which is (GL).
6. **Proof of the local lemma.** Since `<w,e> = Σ μᵢ <uᵢ|e|uᵢ> < 0` over the spectral decomposition of `w`, some
   eigenvector `u` with `μ > 0` has `<u|e|u> < 0`.
   - The hypothesis gives `<v|e|v> ≥ β(1 − 2|<g,v>|²)` for every unit `v`. Applied to `u`, it gives `|<g,u>|² > ½`.
   - A unit `k ∈ ker w` is orthogonal to `u`, so by Bessel `|<g,k>|² ≤ 1 − |<g,u>|² < ½`, hence `<k|e|k> > 0`.
   - So `e` is positive definite on `ker w`, and the block (Schur) estimate gives `w + εe ⪰ 0` for small `ε`. ∎

### EBF — equivariant Barker–Foran [W] (cited in §0, X1(c), X3)

Setting:
- G is a compact group of ipW-orthogonal maps, Haar measure `dg`, `y₀ = ∫ gy dg` (the orthogonal projection onto
  `V^G`), and `V^G ≠ {0}`;
- C is closed, convex, G-invariant, with `C ⊆ C*`;
- `𝓜` is the set of such cones D with `C ⊆ D ⊆ D*`. The closure of the union of a chain stays in `𝓜`, so by Zorn
  there is a maximal M. (Blaschke selection on a volume functional gives the same without Zorn.)

*Proof that `M* = M`.*
1. **Shrunken points stay in `M*`.** For `y ∈ M*`, `conv(Gy) ⊆ M*`. With `u = y − y₀`, the points `z_t = y₀ + tu`
   lie in `conv(Gy)` and satisfy `<z_t, hz_t> = |y₀|² + t²<u,hu>`.
2. **Admissible points lie in M.** If `<z_t, hz_t> ≥ 0` for all h, then `M + cone(G z_t) ∈ 𝓜`. It is closed because
   `M ∩ −cone(Gz_t) = {0}`. By maximality, `z_t ∈ M`.
3. **Elements of `M* \ M` have no fixed part.** Let `c = max_h(−<u,hu>)/|u|²` and
   `t* = min(1, |y₀|/(√c|u|))` (take `t* = 1` if `c ≤ 0`).
   - Suppose `y ∈ M* \ M` with `y₀ ≠ 0`. Then `hz_{t*} ∈ M` for every h, so `0 ≤ <y, hz_{t*}> = |y₀|² + t*<u,hu>`.
   - Taking the minimizing h gives `|y₀|² ≥ t*c|u|²`, which forces `t* = 1`, i.e. `y ∈ M`. Contradiction.
   - So `y₀ = 0` for every `y ∈ M* \ M`.
4. **Nonzero elements of M have a fixed part.** If `m ∈ M` and `m₀ = 0`, then `0 = |m₀|² = ∫<m, gm> dg`, an integral
   of nonnegative continuous values, so `|m|² = 0`.
5. **M is self-dual.** Suppose `y ∈ M* \ M`, and take `m ∈ M \ {0}`, which exists because `V^G ≠ {0}`.
   - `m + sy ∈ M*`. If `m + sy ∉ M`, step 3 gives `(m + sy)₀ = m₀ = 0`, so `m = 0` by step 4 — excluded.
   - Hence `m + sy ∈ M` for all `s > 0`. Since `(m + sy)/s → y` and M is closed, `y ∈ M`. Contradiction.

∎ For `G = {±id}` the hypothesis `V^G ≠ {0}` fails, consistent with AUDIT-S3's correction 2. No label rests on EBF
except the torus row of §0.
