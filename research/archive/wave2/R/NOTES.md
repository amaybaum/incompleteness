## Productivity test (fixed before starting)

A branch counts as a **gem** only if both hold:
1. It yields a fact strictly stronger than "DIM3 is open, and taking it from NB-1 is circular".
2. It does at least one of the following:
   - constrains the space of candidate sources, by an exact countermodel that excludes a class of principles or by
     a theorem that some premise set forces d = 3;
   - exposes a hidden premise.

A branch that only relabels DIM3 is a non-gem.

### N1 — the lower bound d ≥ 3 from DRIVE

**N1.0, d = 0.** Kernel: `not_drivable_singleton` (any V). ✓

**N1.1, d = 1.**
- Kernel coverage is limited to `Icc(−1,1) ⊂ ℝ`.
- General case (written + exact A1):
  - The flow preserves aff Ω (`affineSpan_preserved`, kernel).
  - On the line, h = flow(t₀/2) is affine with slope a, and N = h∘h has slope a² > 0.
  - Exact A1: every real solution of N∘N = id has N = id on the line.
  - This uses no continuity and no boundedness.
- Kernel alternative for a compact segment: `isEmpty_drivability_of_finite_orbits` (ON:124) applies once
  "automorphism orbits of a segment have ≤ 2 points" is proved. That step is written and cheap.
- Verdict: **d ≠ 1 holds for every body**. Status: written + exact; kernel on Icc only.

**N1.2, d = 2 (B6).**
- The ledger's sketch: either Aut(Ω) is finite (B5), or it is compact, so the flow lies in SO(2) and J ∈ O(2), so
  J R J⁻¹ = R^{±1}, and D9 fails.
- **Hidden premise: BOUNDEDNESS** (to get compactness of the automorphism group restricted to aff Ω).
  - Exact countermodel A2: Ω = ℝ² carries a drive. Take flow R(t), t₀ = π, N = −I and J = shear. Then
    J R(π/2) J⁻¹ = [[1,−2],[1,−1]] is not orthogonal, so it equals no flow member, and D9 holds.
  - So "planar ⇒ not drivable" is false without boundedness.
  - Convexity is not needed. Continuity is not needed (exact A3: every O(2) element conjugates R(t) to R(±t)).
- For Ω∞, boundedness is supplied by the [0,1]-valued coordinates (P1b, conditional on SC∞), not by the drive.
- Verdict: **d ≠ 2 given DRIVE + BOUNDED**. Status: written + exact. The hidden premise is NEW, though small.

**N1 result.**
- DRIVE + BOUNDED ⇒ d ≥ 3 (or d = ∞).
- ELEM is **not used** for the lower bound.
- On the EO route below, d = 2 is also excluded independently of B6 (EO forces d odd / d = 3).

### N2 — upper-bound candidates

**(a) One bit / information capacity (Brukner–Zeilinger, Dakić–Brukner).**
- Is it single-system? Only the capacity clause is. Dakić–Brukner's "systems of equal capacity are equivalent"
  plus locality concern composites and subspaces.
- What the single-system clause gives:
  - every centrally symmetric body has capacity ≤ 2 (`card_le_two_of_centrallySymmetric`, kernel);
  - the B–Z total information over d orthogonal axes is |x|² for every d (exact I1).
- So it excludes **no** ball. Fixing "three complementary propositions" is DIM3 restated.
- Not circular. **Fails.** Non-gem; CONFIRMING.

**(b) Hardy K = N^r.**
- It uses composites: K_AB = K_A·K_B, which is LT, and N_AB = N_A·N_B.
- Position on the chain:
  - LT is a premise of K1/NB-1 and belongs to K2's premise level (M table, row LT).
  - Using it does not import NB-1's *conclusion*, so it is not a loop.
  - But it moves DIM3 behind composite premises.
- Binary scope: K(2ⁿ) = (d+1)ⁿ holds for every d (exact I2), so there is **no constraint**.
- The integrality of r needs N = 3 systems through the subspace axiom, which is outside ELEM. Even then,
  d + 1 = 2^r leaves d ∈ {3, 7, 15, …} for r ≥ 2.
- d = 3 is chosen only by Simplicity (minimal K). Given `ball3_drivable` and d ≤ 2 excluded, "the elementary body
  has minimal drivable dimension" ⇔ DIM3, a pure restatement.
- **Fails** as a source. ELABORATING.

**(c) Masanes–Müller 2011 / Masanes–Müller–Augusiak–Pérez-García 2013.**
- Premises: d-ball gbits, LT composite, continuous reversibility, and an entangling reversible interaction. These
  give d = 3.
- It uses composites. It presupposes the d-ball, which it gets via transitivity. It is the same family as NB-1:
  NB-1 is the native-CNOT, discrete version.
- Circularity:
  - on route A (ball3 from DIM3) it is CIRCULAR exactly as NB-1 is;
  - on route B (TRANS first, the ball in every d, then the composite theorem) it is non-circular but composite.
- Not a single-system source. CONFIRMING (M §4.1).

### N3 — maximum skepticism on the favourable branch d5

1. **Strength.**
   - DRIVE + DIM3 ⇒ TRANS(G_D) (K §2, written) and EO(G_D) (hat map, since the closure's identity component is
     SO(3)).
   - So, given DRIVE + compact + FR, {TRANS, EO} ⇔ DIM3 at the elementary level.
   - EO is therefore *not weaker* than DIM3 there. What it adds is unscoped truth and independent content:
     - EO holds for every complex QM system (exact: su(3) on Herm0(3));
     - it fails for real QM (rebit so(2)/ℝ²; real qutrit so(3) on Sym0(3), exact B2/E);
     - it fails for quaternionic QM (so(5)/ℝ⁵, exact);
     - it fails for every spin factor except d = 3.
   - DIM3, by contrast, is false unscoped (qutrit d = 8).
2. **Is ℂ in disguise?** Within Jordan algebras, a dynamical correspondence exists iff the algebra is the
   self-adjoint part of a C*-algebra (Alfsen–Shultz; Barnum–Müller–Ududec 2014, "energy observability").
   - EO is field-neutral in its *statement*, but it is the single-system fingerprint of ℂ.
   - Whether that meets P1 ("ℂ in the conclusion, not the premises") in spirit is an owner judgment. In letter it
     does.
3. **Sourcing.**
   - The landed matrix drive is EO-shaped: `unit g t = exp(iπt·proj g)`, and its generator is π times the sharp
     effect `proj g`.
   - So EO's field-neutral source is the same object as DRIVE's: the non-integer-time gate flow, plus equivariance
     and linearity of generator ↦ effect.
   - EO is OPEN and coupled to DRIVE. Its source is not independent.
4. **Hidden premise inside EO: Lie-algebra level.**
   - For an improper g, the hat map satisfies g·hat(v)·gᵀ = det g · hat(g v) (exact H2).
   - An improper J satisfies D9 (H3).
   - So EO stated as equivariance under the full group would *exclude the qubit*.
   - EO must be stated for 𝔤 (equivalently, for the identity component of the closure). NEW, small.
5. **Same group.**
   - With TRANS for one group and EO for a smaller one, the theorem fails: on B⁴, TRANS holds for isom4 (kernel)
     and EO holds for SO(3)⊕1 (exact E), with d = 4.
   - The hypotheses must refer to one G.
6. **Necessity: is there a single-system route without an EO-like ingredient?**
   - B^d with O(d), d ≥ 4, satisfies every landed single-system item:
     - DRIVE (B1, or SO(3)⊕1, exact);
     - TRANS (ball4, kernel);
     - SharpSeed, PreservesBody, (SEC)/KInf1 with full effects (written; d-ball analogue of `kInf1_ball3_full`);
     - the full self-dual cone;
     - capacity 2 (kernel, Lemma D).
   - Spin factors also satisfy BMU's other single-system postulates: classical decomposability, strong symmetry,
     no higher-order interference (citation).
   - Hence **no principle satisfied by every spin factor can source DIM3**. The missing ingredient must be violated
     by spin factors with d ≠ 3. EO is the known single-system one; LT + interaction is the composite one.
   - Status: written + citation; the instances are kernel/exact. NEW for the corpus.
7. **FR.** FR is used in the proof (Lie theory). No infinite-dimensional countermodel to "TRANS + EO + DRIVE ⇒ d = 3"
   was found: the Hilbert ball fails EO by the same Λ² ≠ Λ¹ argument. FR is kept as a named hypothesis.
