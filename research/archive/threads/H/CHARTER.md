# Thread H — Minimal field-neutral vocabulary for Naimark-style transport (read-only; owner direction, 2026-10-01)

## Question

mechanics (no ℂ, no matrices, no Hilbert space, no tensor product of Hilbert spaces assumed)?

## Scope: four primitives only
1. Composition: system + register.
2. Preparation / attachment of a register.
3. A sharp register readout.
4. Transport (pushforward) of effects through reversible dynamics, followed by discard.

For each primitive determine:
(a) whether the corpus already contains an equivalent notion under another name (exact identifier, file:line at
    6d0abf6b, or corpus location), in field-neutral or only in matrix form;
(b) whether it can be DEFINED from existing field-neutral data rather than axiomatized;
(c) exactly which theorem fails without it (smallest explicit countermodel where possible).

## The decisive test
Can the primitives formulate, field-neutrally,
    e_x = discard/readout ∘ U ∘ (system state ⊗ register seed),
with e_x(x) = 1 and the required sharp normalization — the directional effects (1 + b·r)/2 consumed by
`lorentz_of_effects` (NativeGateBall:105), not merely some effect certain at x — without assuming the desired effect
family beforehand? If yes: that is a genuine candidate for P2 (then a theorem + covering hypothesis + D3 where needed).
If no: identify the FIRST irreducible missing primitive, not a broad axiom.
