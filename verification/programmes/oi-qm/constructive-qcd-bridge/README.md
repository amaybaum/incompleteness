## Initial exact result: gauge covariance does not select a unique action

**Claim (ambient lattice gauge-theory countercontrol, not a native OI
substratum theorem).** For one oriented square plaquette with compact gauge
group `SU(2)`, local gauge covariance permits distinct gauge-invariant
plaquette functionals. Therefore that covariance alone cannot uniquely
select Wilson/Yang–Mills dynamics.

**Derivation.** Give an oriented link `x → y` a variable
`U_xy ∈ SU(2)` with transformation
`U_xy ↦ g_x U_xy g_y^{-1}`. The holonomy around a based plaquette obeys
`U_p ↦ g_x U_p g_x^{-1}`. Hence
`w(U_p) = 1 − (1/2) Re Tr(U_p)` is invariant, and so are both
`S_1 = ∑_p w(U_p)` (Wilson plaquette functional, up to normalization)
and `S_2 = ∑_p w(U_p)^2`. These are *different* gauge-invariant
functionals, not merely different normalizations: on a one-plaquette
configuration take `U_p = diag(e^{iθ}, e^{-iθ})`, attainable with three
identity links and one such link. Then `w = 1 − cos θ`:

| Holonomy | `w` | `w²` |
| --- | ---: | ---: |
| `θ = π/3` | `1/2` | `1/4` |
| `θ = π` | `2` | `4` |

The ratio `S_2/S_1` changes from `1/2` to `2`. Both actions pass the
same gauge-transformation check, but cannot be proportional across all
configurations. This establishes only **non-uniqueness from covariance
alone**. It does not show that both actions have the same continuum
universality class, that either is generated by the actual OI bijection,
or that OI's other premises fail to select one.

**Control and countercontrol:** conjugating the plaquette by arbitrary
`g_x ∈ SU(2)` preserves both traces; the two explicitly evaluated
holonomies demonstrate unequal action ratios. The proof is exact
algebra (not a Lean certificate or numerical simulation).

## Bounded correspondence problem

The target must be an **explicit operational matching map**, not an
analogy between two uses of a lattice. Let `A_GI` denote a specified
finite test algebra of gauge-invariant loop/correlation observables,
`E_OI` an OI observable-channel expectation on a sourced carrier,
and `E_YM` the corresponding lattice-QCD/constructive-QFT expectation.
The first candidate goal is to establish, for a declared finite set of
loops, volume/time/energy range and state-preparation protocol,

`sup_{O ∈ A_GI, ||O|| ≤ 1} |E_OI(O) − E_YM(O)| ≤ ε`,

with the same normalization and explicit `ε` dependence on scale,
volume and preparation. An exact equality is **not** assumed. Nor does
a tree-level `O((E/M_Pl)^2)` dispersion estimate alone control
interacting/nonperturbative Wilson loops.

### Ordered investigation and predeclared dispositions

**A. Native action-selection check (first active target).**
Trace the actual OI `(S, φ)` and allowed link/coupling family through
the observer interface and H-link/H-cust assumptions. Determine whether
the induced effective gauge-invariant dynamics chooses `S_1`,
permits an `S_2` term, or leaves the action underdetermined.
A rigorous map plus derivation would be a **conditional bridge**;
a concrete alternative meeting the same premises is a **non-uniqueness
witness**; an unsourced carrier is **PARKED (physical sourcing gap)**.
Do not mistake a Wilson action *postulate* for a derivation.

**B. Correlator/loop matching (only after A has a sourced candidate).**
Pick a minimal nontrivial finite loop set and a connected correlator.
Specify a standard lattice-gauge baseline and a trivial/decoupled
countercontrol, the gauge-invariant observable map, boundary conditions,
state/measure, coupling calibration and numerical/exact error budget
*before* comparing outcomes. Failure of either control voids any match.
A match on a finite set establishes only that finite test, never full
QCD equivalence.

**C. Coarse-graining/RG comparison (conditional).**
State a concrete commuting diagram from the microscopic dynamics to
observer restrictions and from lattice gauge theory to RG-blocked
observables. Test whether it intertwines both the chosen observable
algebra and the dynamics/measure. Partial trace, conditional
expectation and Wilsonian RG are not automatically identical operations.
A counterexample to commutation closes the *specific* proposed map,
not all conceivable maps.

**D. Public-proof compatibility gate (deferred).**
When the OpenAI working group releases a checkable theorem, compare its
gauge group, fermionic content, nontriviality, spacetime regularity,
OS/Wightman requirements and limit ordering against the scoped
candidate. Do not infer a mass gap from existence. A mismatch is a
named obstacle or non-equivalence, not evidence against either theory
outside the compared scope.
