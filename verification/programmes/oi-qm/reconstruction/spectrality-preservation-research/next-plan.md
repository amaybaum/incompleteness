Research/design only. The starting record is `result.md`; no native freeze,

This file states the decision rule before the new certificate computations.

The retained domain is an independently specified closed convex pair cone
SEP ⊆ C ⊆ maxCone, trace normalization, and the separately supplied inventory
premises guaranteeing the actual stopped maps Phi_k. SP is the external
classical-decomposability postulate, without strong symmetry or homogeneity.

unitary and Γ partial transpose on the second native token. A theorem counts
only with a written argument for arbitrary U: native product admission must
force product-ray preservation, and the latter must be proved to force a
local unitary or local unitary composed with SWAP. If so, derive equality
with the original coPSD and preservation of the actual Phi_k. An entangling tilt
that fails native products is rejected, even if SP and map failure hold.

Second test whether a normalized centrally symmetric base, including an
ellipsoid or a linearly transported Lorentz-cone base, can meet the same
domain. The argument must cover every center, not just the maximally mixed
matrix. A rejection closes only this model class, not generic SP.

New exact certificates will check the product-preserver determinant lemma,
the pure-projector partial-transpose criterion, local/SWAP covariance on a
spanning matrix basis, an entangling-tilt domain rejection, and the four-outcome
central-symmetry obstruction. Quantum and classical comparisons use Phi_1.

phase, transpose, product admission, or center/normalization assumptions must
be rejected before any computational verdict prints. Prior saved outputs
and hash lists remain unchanged. Finite certificates support the universal
written argument; they do not replace it.

If this yields no common-domain counterexample, generic SP ⇒ preservation
stays open. Retain both original fixture exclusions, the Q3-inclusion gate,
and the full-flow disguise test, with their original evidence levels. This
is a bounded forward record, not evidence of a physical source for SP.
