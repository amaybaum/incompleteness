# Node 9 follow-up: can an embedded observer reconstruct the current hidden state? (exploratory design evidence)

**Status.** This is exploratory. It counts as exploratory until an independent review accepts its premises. It is design evidence, not a preregistered run, and it renders no M0–M5 verdict. Base: a detached worktree of `231ec13c`, read-only. Arithmetic is exact throughout: F₂ bitmask linear algebra, plus forward simulation of explicit states. There is no floating point. The engine `f2.py` is copied unchanged from `mc-node9/design/c1` (sha256 `855df88d…`, the same as C-i's). Every statement below is scoped to the regime and bounds it names. Nothing here is a claim about OI in general.

## 0. Verdict lines

The two questions are kept separate, as the owner asked on 2026-10-21. "Memory" means every visible cell present at the stopping time (R2). Every stopping time is evaluated (R1).

- **Q-forget:** does a particular apparatus forget enough to preserve uncertainty?
- **Q-build:** can an embedded observer build another allowed apparatus that keeps the information? C5 needs Q-build.

| regime | Q-forget | Q-build |
|---|---|---|
| **E1** fixed global update, fixed graph and region | **Restriction holds for the single-site apparatus, in the learning sense.** Lemma L1 (§3) covers every graph, every n, every t and every symplectic evolution. Exhaustive checks at n ≤ 6 and on lattice-like graphs agree. E1-C1 gives no point mass at any stopping time. **Not in the support sense:** E1-K2 reaches a point mass by overwriting the toy with the pointer's clean pair. | **Reconstruction achieved.** Witness W-E2: n = 5, R = {pointer, one memory site behind it}, and the toy has two hidden bath neighbours. The current toy is a point mass given the visible cells at t = 4 and t = 12, while its prior support at those times is 4. |
| **E2** controller and memory on an enlarged graph | Same as E1. The update is linear, so a controller's program only adds known constants and cannot steer anything (§2.2). L1 applies unchanged. | **Reconstruction achieved.** W-E2 is itself an E2 arrangement: one apparatus plus one memory site. Smaller E2 witnesses exist from n = 3 (§4). |
| **E3** external selection of couplings (AP-2, a control resource, not generated by the lattice) | L1 holds for every gating word, since every gated step is symplectic. Checked over all words up to depth 6 (depth 4 on K₄). | **Reconstruction achieved.** Witness W-E3: W4 in E3 with one reused pointer, re-cleaned each time by exchange with a fresh clean memory site. The three memory sites alone give a point mass from t = 10, with prior 4. The W4/K-EXTHIST control is green in that arena. With a fresh bath at every read, the W4 control is red, so that sub-arena gets no verdict. |

**In one sentence:** within these bounds, the restriction is a **one-canonical-pair memory budget**, not a barrier to accumulating records. One clean visible site can never completely know a uniformly unknown toy pair (L1). Two clean visible sites can, on fixed graphs with no external choices, from the current visible cells alone.

The C-i waiting counterexample (point mass at step 4) needs the external history (K-EXTHIST). Without that history, the same apparatus never reaches a point mass (E1-C1). An observer who builds one more memory site gets complete knowledge back, without any history (W-E2).

## 1. Operation classes and where the history lives (fixed before computing)

- **State and update.** The update is Main.md l. 290, u′_x = Σ_{z∼x} u_z + v_x, v′_x = u_x, over F₂. The visible sector is "the sites of a region R" (l. 292). Both coordinates of a visible site are visible.
- **Initial conditions.**
  - Clean declaration FULL: both coordinates of every visible site start clean at 0. By linearity, any known value gives the same result.
  - Variants: U (only the u coordinates clean), V (only v), NONE (no clean coordinate).
  - Every other coordinate is i.i.d. uniform (the counting measure).
- **Memory: physically, only the visible cells R at the stopping time.**
  - That is 2|R| bits, evolving under the same update as everything else.
  - There is no external history, no feedback reset and no free visible permutation. The observer knows the declared clean values, the graph and t (assumption H4).
  - Information about the toy's current state is measured as the toy's posterior support given every visible cell, at every t in one full period of the update.
  - Because M^ord = I and every M is a bijection of a finite set, the period is a complete time certificate (R1).
- **K-EXTHIST** is the same protocol plus a free record of every visible configuration from time 0 to t.
- **E1.** One fixed graph G, one region R and one toy site τ ∉ R. Only the global update runs.
- **E2.** E1 on an enlarged graph whose extra visible sites serve as memory or controller. The controller's "program" is the clean initial values of its sites.
- **E3.** At each step an external controller picks the active edge set S of a base graph. A site with no active edge maps (u, v) → (v, u).
  - The selection is open-loop. An adaptive selection would itself be an external memory of the readings, which is K-EXTHIST.
  - E3 supplies AP-2 as a control resource and is not counted as generated by the lattice.
- **"Learning" vs "overwrite".**
  - A point mass is called *learning* when the toy's current state at that t has prior support 4: it is undetermined without records.
  - Otherwise it is *overwrite*: part of the toy's current state is a function of the clean inflow.
  - The requested quantity is the minimum posterior support, and it is reported in both senses.

**Formula.** In the Heisenberg picture, the toy's posterior support given records F is 2^(rank(F_u + T_u) − rank F_u). Here X_u means X restricted to the unknown coordinates. The value is the same in every branch.

**§A.21 control (`check_core.py`, GREEN).** The formula was checked against forward simulation of explicit states: no matrix powers and no rank algebra. Coverage:
- every graph on n ≤ 4 sites, every region, every toy, every declaration, t ≤ 6;
- both final-memory and K-EXTHIST records;
- every assignment of the clean values at n ≤ 3, and all-0 / all-1 at n = 4.

Result: 92 424 cases, 0 mismatches. The isomorphism-class counts 1, 2, 4, 11, 34, 156 match OEIS A000088.

## 3. Lemmas (exact; proofs short enough to check by hand; review pending)

Let Φ be any symplectic linear bijection: any product of displayed updates on any graphs, any E3 gating word, and any symplectic visible operation. Cell values at time t are the functionals (rows of Φ). K denotes the span of the clean coordinate functionals.

- **L0 (no clean resource ⇒ no knowledge of the present).** If no coordinate is clean, the initial distribution is uniform on Ω and Φ preserves it. Any two disjoint cell sets at one time are therefore independent.
  - Records of the *past* are still free. For example, under NONE the current visible site can equal the toy's initial state (`persist` witnesses, §4).
- **L1 (one-pair lemma).** Let R be a single site with both coordinates clean, every other coordinate uniform, and τ a hidden site whose current state has prior support 4. Then the toy's posterior support given the current visible site is ≥ 2.
  - *Proof.*
    - Write the toy's current functionals as g₁ = φ₁ + k₁ and g₂ = φ₂ + k₂, with φᵢ in the 2-dimensional span W_V of the visible site's functionals and kᵢ ∈ K.
    - Prior support 4 makes φ₁ and φ₂ independent modulo K. They are then a basis of W_V, so ω(φ₁, φ₂) = 1.
    - W_V ⊥ the toy's functionals, because distinct coordinates of a symplectic image are ω-orthogonal. Hence:
      - ω(φ₁, g₁) = 0 gives ω(φ₁, k₁) = 0;
      - ω(φ₁, g₂) = 0 gives ω(φ₁, k₂) = 1;
      - ω(φ₂, g₁) = 0 gives ω(φ₂, k₁) = 1.
    - Expanding ω(g₁, g₂) = 1 then gives ω(k₁, k₂) = 0.
    - Both kᵢ are nonzero, and K is 2-dimensional symplectic, so k₁ = k₂. That contradicts ω(φ₁, k₁) = 0 ≠ 1 = ω(φ₁, k₂). ∎
  - It holds for every graph, every n, every t, and every E3 word.
  - It does not cover:
    - external history (K-EXTHIST is not a bijection);
    - overwrite point masses (E1-K2);
    - non-uniform preparations, beyond the owner's C1 check;
    - more than one visible site.
- **L2 (budget beyond one pair; derivation, not yet reviewed).** Consider r memory pairs and m target pairs with uniform prior.
  - Complete learning needs m ≤ r (capacity).
  - At r = m, it needs v ↦ ω(v, (I + B*B)v′) to be non-degenerate, where B is the memory → target read-off map.
  - For m = 1, B*B = I, which recovers L1. For m ≥ 2 the condition can hold.
  - `mtarget.py`, every graph n ≤ 6, every region, every target set, one full period:
    - r = 1 learns nothing, for m = 1..5;
    - r = 2: m = 1 learnt in 1061 cases, m = 2 in 140, m = 3 in 0;
    - r = 3: m = 3 learnt in 594.
- **L3 (known displacement).** If memory determines a toy functional g = f + k, then its conjugate partner g′ satisfies ω(k, g′) = 1. In other words, complete knowledge from memory requires the conjugate coordinate to carry a displacement by the clean input's conjugate.
  - That displacement is *known*. So, within this lattice, the back-action of every complete embedded record is sourced by clean visible coordinates and provides no restriction (requirement 5).

## 5. Pressure tests (§A.31), backgrounds and witnesses

**Families** (`e2_families.out`; every t in the period). Each line gives the arrangement and the learning result.

- **A.** Path made of a memory chain of m sites, then the pointer, the toy, the bath and a reservoir of L − 1 sites. m ≤ 4, L ≤ 6, n ≤ 12: **no learning at any t**. Overwrite point masses occur for some (m, L). A memory chain behind the pointer does not help on a path.
- **B.** Toy with k leaf baths, one pointer and a memory chain m:
  - learning for k = 2 and k = 4 when m ≥ 1, first at t = 4;
  - none for k = 1 or 3, and none for m = 0, which is L1.
  - The parity is structural. For an even number of leaf baths the toy reads their bright mode u₃ + u₄, which never records the toy, because 2u₀ = 0 over F₂.
- **Lattice-like graphs.** Every R and toy, one full period:
  - path P₇: learning in 0 / 2 / 166 cases for |R| = 1 / 2 / ≥ 3;
  - cycles C₆ and C₈, grids 2×3, 2×4 and 3×3, cube 2×2×2: learning **only for |R| ≥ 3** (for example 995 of 1971 on 3×3, and 384 of 792 on the cube);
  - |R| = 1: none on every graph.

**W-E2 in detail** (FULL, every t = 1..15):
- **Toy support given the visible cells:** 2 2 2 **1** 2 2 2 4 2 2 2 **1** 2 2 2. The prior is 4 throughout.
- **Erasure.** The knowledge is not enduring: it is erased at the next step and recurs only at t = 12 (R1).
- **Cell contents at t = 4 (clean values 0).**
  - Pointer: (u₃ + u₄, v₃ + v₄).
  - Memory: (u₀ + v₃ + v₄, v₀ + u₃ + u₄).
  - Toy: (v₃ + v₄, u₃ + u₄).
  - So the toy's current state is the bath's bright mode, which the pointer also holds. Its initial content has moved into memory, mixed with that mode.
- **Backgrounds and copying.** Two backgrounds run as protocols on the same graph never learn:
  - B0 (all R–H edges cut): min support 4;
  - non-copying (pointer–memory edge removed): min support 2.
  - Relative to both, the copying arrangement's disturbance D is "in memory".
  - Copying, not the mere passage of time, is what makes the current state learnable.

**W-E3** (`e3_w4.out`).
- **Arena.** One pointer (1), one reused bath (5), three clean memory sites (2, 3, 4).
- **Word.** The read step activates {0–1, 0–5}. Each store is an edge-on/edge-off word on {1, mᵢ} whose two-site map exchanges the pointer pair with the memory pair. The two-site group generated by these words has 12 elements, and no exact even-length site exchange exists in it. The stores used are EEEO, EEE and EEE, for 13 steps.
- **Every stopping time:**
  - support given all visible cells: 2 ×9, then **1 1 1 1** at t = 10..13;
  - prior: 4 throughout;
  - memory sites alone: point mass from t = 10;
  - K-EXTHIST: the same.
- **Final memory.** (0, p), (q + u₅, 0), (q + u₅, 0). The toy is (q + u₅, p), so its current state is held twice over in memory.
- **Backgrounds** (same timing).
  - With the stores idle (non-copying), support stays 2 throughout. The toy then differs from the copying run by (0, u₂ + u₃), which is **known** (clean).
  - With every step idle, support stays 4.
  - So the store adds no unknown kick. Retention costs one fresh clean memory pair per read.
- **Fresh bath per read** (512 skeleton words, pads 0..3, store words of length ≤ 6). Even K-EXTHIST stays at support 2. The W4 control is red there, so no regime verdict is drawn from it. With full history it behaves as the owner's REC model does.

## 6. Hidden assumptions (named; each one could change the result)

- **H1.** The update is linear: Main.md l. 290 over F₂.
  - E2 ≡ E1 rests on this, since a linear controller can only add known constants.
  - A nonlinear bijection could embed real conditional control. That is outside Main.md l. 320's scope and not searched.
- **H2.** Clean resources are visible sites with both coordinates clean (FULL). Everything known comes from them (L0).
  - Under U or V a single site never reaches a point mass, but |R| ≥ 2 still learns (n ≤ 6).
  - The clean budget is the operative resource. A model that withholds clean visible pairs changes the answer, and it must state that withholding as a postulate.
- **H3.** The hidden prior is uniform and independent (the counting measure). Non-uniform preparations were checked only in the owner's C1 family.
- **H4.** The observer knows t, the graph and the clean values. Witnesses hold only at specific t (W-E2 at t = 4 and 12 of period 16). Knowing t is a clock resource. An embedded clock would need further clean visible sites and was **not modelled**.
- **H5.** Knowledge is defined as conditional support. The decoder is not embedded.
- **H6.** The toy is one site, and the partition is at site level (l. 292).
- **H7.** E3 is open-loop. Adaptive selection is K-EXTHIST by construction.
- **H8.** No C1–C4 regime constraint (for example C2-slow) is imposed on the witnesses. In particular, W-E2's bath is two leaves whose bright mode kicks the toy but never records it.

**Skepticism applied to the favourable branch, the restriction L1.**
- It survives longer horizons and alternative graphs: it is proved for all t and all symplectic Φ.
- It does **not** survive a larger memory. One extra clean visible site removes it (W-E2, W-E3, L2), so it is a one-pair budget, not a mechanism that blocks accumulation.
- The reconstruction branch was pressure-tested too. Every witness:
  - conditions on all visible cells;
  - is checked at every stopping time;
  - has prior 4 at its point mass;
  - is reproduced by the independent forward simulation at n ≤ 4.

**Productivity test.** Is the finding stronger than the restatement "symplectic, so bounded"? Yes:
- L1 is a sharp one-pair obstruction, and |R| = 2 breaks it;
- C-i's 4-step reconstruction is located in the external history;
- Q-build succeeds embedded.

Classification: **NEW** (L1 and the memory-budget form; the K-EXTHIST dependence of the C-i counterexample) and **CONFIRMING** (L3: known back-action gives no restriction).

**Assumption-watch markers.**
- (a) Any restriction that holds for "the pointer" must be re-tested with one more clean visible site.
- (b) A reconstruction at a single t is not an enduring state of knowledge. Report every stopping time.
- (c) Free history counts as memory, and it is unbounded memory.
