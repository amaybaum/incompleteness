**In one sentence:** Within these bounds, the restriction is the case of one read-out pair with one clean pair (L1). Two clean visible sites determine the toy completely from the current visible cells alone, on fixed graphs with no external choices.

In E1 that knowledge is transient: W-E2 reaches support 1 at 2 of its 15 stopping times. Accumulation of retained records is shown only in E3 (W-E3), under external gating (AP-2).

The C-i waiting counterexample (point mass at step 4) needs the external history (K-EXTHIST), as C1-REPORT §9.1 already records. ## 1. Operation classes and where the history lives (fixed before computing)

- **State and update.** The update is Main.md l. 290, u′_x = Σ_{z∼x} u_z + v_x, v′_x = u_x, over F₂. The visible sector is "the sites of a region R" (l. 292). Both coordinates of a visible site are visible.
- **Initial conditions.**
  - Clean declaration FULL: both coordinates of every visible site start clean at 0. By linearity, any known value gives the same result. FULL is the clean-visible-site resource C-i declared (C1-REPORT l. 41, "clean visible pointer site (Q and Q̄)"); the corpus does not derive it (H11).
  - Variants: U (only the u coordinates clean), V (only v), NONE (no clean coordinate).
  - Every other coordinate is i.i.d. uniform (the counting measure).
- **Memory: physically, only the visible cells R at the stopping time.**
  - That is 2|R| bits, evolving under the same update as everything else.
  - There is no external history, no feedback reset and no free visible permutation. The observer knows the declared clean values, the graph and t (assumption H4).
  - Information about the toy's current state is measured as the toy's posterior support given every visible cell, at every t in one full period of the update.
  - Because M^ord = I and every M is a bijection of a finite set, the period is a complete time certificate (R1).
- **K-EXTHIST** is the same protocol plus a free record of every visible configuration from time 0 to t.
- **E1.** One fixed graph G, one region R and one toy site τ ∉ R. Only the global update runs.
- **E2 reduces to E1.** E2 was posed as E1 on an enlarged graph whose extra visible sites serve as memory or controller, with the controller's "program" the clean initial values of its sites. With a linear update the clean values enter every cell as a known affine shift M^t(c − c′). The posterior support is therefore independent of the program, and the set of reachable maps stays {M^t}. E2 is E1 with |R| ≥ 2, and a linear embedded controller cannot reproduce E3's gating. The tables below split by |R| only.
- **E3.** At each step an external controller picks the active edge set S of a base graph. A site with no active edge maps (u, v) → (v, u).
  - The selection is open-loop. An adaptive selection would itself be an external memory of the readings, which is K-EXTHIST.
  - E3 supplies AP-2 as a control resource and is not counted as generated by the lattice.
- **"Learning" vs "overwrite".**
  - A point mass is called *learning* when the toy's current state at that t has prior support 4: it is undetermined without records.
  - Otherwise it is *overwrite*: part of the toy's current state is a function of the clean inflow.
  - The learning class includes the case where the toy's current state is a mode the pointer also received, with none of the toy's own content left (H10; W-E2 is one).
  - The requested quantity is the minimum posterior support, and it is reported in both senses.

**Formula.** In the Heisenberg picture, the toy's posterior support given records F is 2^(rank(F_u + T_u) − rank F_u). Here X_u means X restricted to the unknown coordinates. The value is the same in every branch.

**§A.21 control (`check_core.py`, GREEN).** The formula was checked against forward simulation of explicit states: no matrix powers and no rank algebra. Coverage:
- every graph on n ≤ 4 sites, every region, every toy, every declaration, t ≤ 6;
- both final-memory and K-EXTHIST records;
- every assignment of the clean values at n ≤ 3, and all-0 / all-1 at n = 4.

Result: 92 424 cases, 0 mismatches. The isomorphism-class counts 1, 2, 4, 11, 34, 156 match OEIS A000088. `check_core` shares `f2.lattice_update` and `f2.apply` with the formula path; the reviewer's equation-level simulation (`review/indep.py`) and recounts agree with it.

## 3. Lemmas (exact; proofs short enough to check by hand)

Let Φ be any symplectic linear bijection: any product of displayed updates on any graphs, any E3 gating word, and any symplectic visible operation. Cell values at time t are the functionals (rows of Φ). K denotes the span of the clean coordinate functionals.

- **L0 (no clean resource ⇒ no knowledge of the present).** If no coordinate is clean, the initial distribution is uniform on Ω and Φ preserves it. Any two disjoint cell sets at one time are therefore independent.
  - Records of the *past* are still free. For example, under NONE the current visible site can equal the toy's initial state (`persist` witnesses, §4).
- **L1 (one-pair lemma).** Let R be a single site with both coordinates clean, every other coordinate uniform, and τ a hidden site whose current state has prior support 4. Then the toy's posterior support given the current visible site is ≥ 2.
  - *Proof.*
    - Suppose the posterior support is 1. Then each toy functional lies in W_V + K: write the toy's current functionals as g₁ = φ₁ + k₁ and g₂ = φ₂ + k₂, with φᵢ in the 2-dimensional span W_V of the visible site's functionals and kᵢ ∈ K.
    - Prior support 4 makes φ₁ and φ₂ independent modulo K. They are then a basis of W_V, so ω(φ₁, φ₂) = 1.
    - W_V ⊥ the toy's functionals, because distinct coordinates of a symplectic image are ω-orthogonal. Hence:
      - ω(φ₁, g₁) = 0 gives ω(φ₁, k₁) = 0;
      - ω(φ₁, g₂) = 0 gives ω(φ₁, k₂) = 1;
      - ω(φ₂, g₁) = 0 gives ω(φ₂, k₁) = 1.
    - Expanding 1 = ω(g₁, g₂) = ω(φ₁, φ₂) + ω(φ₁, k₂) + ω(k₁, φ₂) + ω(k₁, k₂) = 1 + 1 + 1 + ω(k₁, k₂) gives ω(k₁, k₂) = 0.
    - k₁ ≠ 0 since ω(φ₂, k₁) = 1, and k₂ ≠ 0 since ω(φ₁, k₂) = 1. In the 2-dimensional symplectic space K, any two distinct nonzero vectors pair to 1, so ω(k₁, k₂) = 0 forces k₁ = k₂. That contradicts ω(φ₁, k₁) = 0 ≠ 1 = ω(φ₁, k₂). ∎
  - *Scope.* The proof uses only that Φ is symplectic, that the read-out is one canonical pair of the image, that K is one hyperbolic pair, and that the prior support is 4. It does not use the lattice, or that the clean pair and the read-out are the same site. Each of the two one-pair hypotheses is necessary: one clean pair with two visible sites learns, and two clean pairs read through one site learn (§4, `review/l1_attack.out` [5]; W-E2).
  - It holds for every graph, every n, every t, and every E3 word. Every gated step is M_S = [[L_S, I], [I, 0]] with L_S symmetric; self-loops and multi-edges keep L symmetric. Break attempts (`review/l1_attack.py`): 171 868 checks over every symmetric L with self-loops at n ≤ 4, 168 000 over random E3 words with self-loops and multi-edges, 28 000 over random symplectic maps with clean and read sites chosen independently, 0 violations; a non-symplectic bijective countercontrol breaks the bound (support 4 → 1).
  - It does not cover:
    - external history (K-EXTHIST is not a bijection);
    - overwrite point masses (E1-K2);
    - non-uniform preparations, beyond the owner's C1 check;
    - more than one visible site, or more than one clean pair;
    - a read-out that is not a whole canonical pair, such as the coordinate-level form Q visible with P hidden (H6).
- **L2 (beyond one pair).** Consider a visible span W_V of r site pairs (rows F, 2r of them), clean span K, and m target pairs (rows T, span W_T) with full prior (rank T_u = 2m).
  - *Capacity* (theorem). Rows F and T of the invertible Φ are independent. Complete learning means T_u ⊆ span F_u. Restriction to the unknown coordinates then maps span(F ∪ T), of dimension 2r + 2m, onto span F_u, so its kernel, which lies in span K, has dimension 2r + 2m − rank F_u ≥ 2m. Hence complete learning of m target pairs needs at least 2m clean coordinates and, since 2m ≤ rank F_u ≤ 2r, at least m visible pairs. Under FULL (K the clean span of the same r sites, dim K = 2r) this gives m ≤ r.
  - *r = m* (necessary condition) [W, review of b71199a8]. Under FULL with r = m, write g = ψg + κg for g ∈ W_T, with ψg ∈ W_V and κg ∈ K. Define B := ψ, the memory → target read-off map W_T → W_V, and B\* := ψ†, its symplectic adjoint (ω(h, ψ†a) = ω(ψh, a) for h ∈ W_T, a ∈ W_V). Full prior makes ψ injective, hence bijective onto W_V. Orthogonality ω(W_V, W_T) = 0 gives ω(ψh, κg) = ω(ψh, ψg); since W_V is non-degenerate, κ is injective, hence bijective onto K. Expanding ω(g, g′) gives ω(κg, κg′) = ω(g, g′) + ω(ψg, ψg′) = ω(g, (I + B\*B)g′). K is non-degenerate, so I + B\*B must be invertible: v ↦ ω(v, (I + B\*B)v′) is non-degenerate on W_T. For m = 1, B\*B = det B · I = I, so the condition fails, which is L1. The identity and non-degeneracy held in all 734 learnt r = m cases at n ≤ 6 (140 at m = 2, 594 at m = 3; `review/l2_check.out`). Sufficiency is not claimed; that the condition can hold for m ≥ 2 rests on those cases.
  - *Counts* (exhaustive observations at n ≤ 6; `mtarget.py`, every graph, every region, every target set, one full period; reproduced independently by `review/l2_check.py`):
    - r = 1 learns nothing, for m = 1..5 (also a corollary of L1 and capacity);
    - r = 2: m = 1 learnt in 1061 cases, m = 2 in 140, m = 3 and 4 in 0;
    - r = 3: m = 1, 2, 3 learnt in 5026, 2913, 594;
    - r = 4: m = 1, 2 in 3374, 1210; r = 5: m = 1 in 628.
- **L3 (known displacement).** If memory determines a toy functional g = f + k, then its conjugate partner g′ satisfies ω(k, g′) = 1. In other words, complete knowledge from memory requires the conjugate coordinate to carry a displacement by the clean input's conjugate.
  - That displacement is *known*. Within this lattice, under FULL, the back-action of every complete embedded record is sourced by clean visible coordinates and is itself known.

## 5. Pressure tests (§A.31), backgrounds and witnesses

## 6. Hidden assumptions (named; each one could change the result)

- **H1.** The update is linear: Main.md l. 290 over F₂.
  - E2 ≡ E1 rests on this, since a linear controller can only add known constants.
  - A nonlinear bijection could embed real conditional control. That is outside Main.md l. 320's scope and not searched.
- **H2.** Clean resources are visible sites with both coordinates clean (FULL). Everything known comes from them (L0).
  - Under U or V a single site never reaches a point mass, but |R| ≥ 2 still learns (n ≤ 6).
  - Both the number of clean coordinates and the number of visible pairs are operative. Complete learning of m target pairs needs at least 2m clean coordinates and at least m visible pairs. One visible pair with one clean pair never suffices (L1). One clean pair with two visible sites can (n = 3, t = 2).
- **H3.** The hidden prior is uniform and independent (the counting measure). Non-uniform preparations were checked only in the owner's C1 family.
- **H4.** The observer knows t, the graph and the clean values. Witnesses hold only at specific t (W-E2 at t = 4 and 12 of period 16). Every verdict of the form "some t" is realized only by an observer who stops at that t. Knowing t is a clock resource. An embedded clock would need further clean visible sites and was **not modelled**.
- **H5.** Knowledge is defined as conditional support. The decoder is not embedded.
- **H6.** The toy is one site, and the partition is at site level (l. 292). L1 needs the read-out to be a whole canonical pair; the coordinate-level form, Q visible with P hidden, is not covered.
- **H7.** E3 is open-loop. Adaptive selection is K-EXTHIST by construction.
- **H8.** No C1–C4 regime constraint (for example C2-slow) is imposed on the witnesses. In particular, W-E2's bath is two leaves whose bright mode kicks the toy but never records it.
- **H9 (building).** "Building an apparatus" means an external, design-time choice of graph, region and clean supply. No process inside the dynamics constructs it, so the Q-build verdicts are existence statements over fixed arrangements.
- **H10 (learning definition).** "Learning" means prior 4 at the evaluation time. That definition puts replacement of the toy by a mode the pointer shares (W-E2) in the same class as knowing the toy's own content. It also says nothing about partial gains when the prior is 2.
- **H11 (resource status of FULL).** FULL is the clean-visible-site resource that C-i declared (C1-REPORT l. 41). The corpus does not derive it. Supplying several FULL sites is a model declaration that every Q-build witness depends on: W-E3 uses 4 clean pairs.

**Skepticism applied to the favourable branch, the restriction L1.**
- It survives longer horizons and alternative graphs: it is proved for all t and all symplectic Φ.
- It does **not** survive relaxing either of its one-pair hypotheses. A second visible site with no clean coordinate removes it (§4, mixed declarations), and so does a second clean pair read through one site (W-E2). In E1 the resulting knowledge is transient; retained records are shown only under external gating (W-E3).
- The reconstruction branch was pressure-tested too. Every witness:
  - conditions on all visible cells;
  - is checked at every stopping time;
  - has prior 4 at its point mass;
  - is reproduced by the independent forward simulation at n ≤ 4, and W-E2 and W-E3 by the reviewer's equation-level simulation.

**Productivity test.** Is the finding stronger than the restatement "symplectic, so bounded"? Yes:
- L1 is a sharp obstruction for one read-out pair with one clean pair, and relaxing either breaks it;
- C-i's 4-step reconstruction is located in the external history, now computed exactly;
- Q-build succeeds embedded, at isolated stopping times in E1 and retained in E3.

Classification:
- **NEW** within the programme, pending the literature gate (Step 4): L1, and the r = m form of L2. Epistemically restricted symplectic theories (Spekkens-type knowledge balance) should be checked before NEW stands.
- **ELABORATING:** the K-EXTHIST dependence, which C-i §9.1 already records; EMB computes it exactly.
- **CONFIRMING:** L3.

**Assumption-watch markers.**
- (a) Any restriction that holds for "the pointer" must be re-tested with one more visible site and with one more clean pair, separately.
- (b) A reconstruction at a single t is not an enduring state of knowledge. Report every stopping time.
- (c) Free history counts as memory, and it is unbounded memory.
