## Result

The verdict is `results/verdict.txt`, generated by `verdict.py` from `results/measurements.json` alone. A local
regeneration is byte-identical.

**Governing classification (condition (d) read as `abs`): COUNTEREXAMPLE.** It is a counterexample to the universal
form of `book/ch18-beyond.md:114`, the statement that randomness "is unpredictable by any embedded observer regardless
of its origin". It rests on the witnesses in one admissible cell (`G_clk`, n = 5, `emb_m2_all`, K = 7), each meeting
conditions (a)–(f) of §6. The reported witness is:

| | |
|---|---|
| Generator | `G_clk`, n = 5, primitive polynomial z⁵ + z² + 1 |
| Observer class | embedded, active (subclass `emb_m2_all`), m = 2 memory bits |
| Observer tables | ρ₀ = [1,0,2,3], ρ₁ = [0,2,3,1], a = [1,0,0,1]; guess χ ≡ 0 (observer index 2361) |
| Horizon | K = 7, window K′ ∈ [4, 7] |
| Prediction advantage | Pr[χ(v_{K′}) = X_{K′}] − 1/2 = 1/8, 5/32, 5/32, 1/8 |
| Footprint | m + ⌈log₂(K+1)⌉ + 1 = 2 + 3 + 1 = 6 = θ (θ = n+1). The table size is 31 bits, held in the dynamics and not charged. |
| Recurrence bound | K_cx = 20; the μ-median orbit length is 40 |
| Knowledge level | K1: the tables are chosen for G_clk(z⁵+z²+1). |
| Family-wide status | None: the observer gives no window on the other five primitive quintics, and no observer in the subclass gives a window at K = 7 on every member of 𝔉_clk(5). |
| Realization conditions | T-level (C1) holds; C2–C4 not checked |

**Verification layer.** The statement is an existence claim, verified by exact enumeration of the joint state with
rational arithmetic. It holds for this generator, this observer and this horizon only.

**Extent of the cell.**
- Under `abs`, 36 (observer, χ) pairs meet (a)–(f). They come from 18 observers, each counted with χ and with its
  complement.
- These reduce to 3 observers, up to relabelling of the memory states that fix v₀:
  - the reported witness, with the constant guess χ ≡ 0, which is sign-consistent;
  - one with a non-constant χ, also sign-consistent (advantages 1/8, 1/8, 11/64, 1/8);
  - one that alternates in sign (1/8, 1/8, −1/8, −1/8) and qualifies only under `abs`.
- Under `signed`, 12 pairs qualify.
- The verdict's "1 witness(es)" counts this one cell, not observers.

**Mechanism.**
- For the reported witness (χ ≡ 0), the guess is correct exactly when the post-intervention system bit
  c_t = x_t ⊕ a(v_{t+1}) equals the generator's next output Y_t.
- c_t is a function of the past record, and Pr[Y_t = c_t] − 1/2 at t = 3..6 is the same curve.
- The interventions select the clocking step, and so which bit of the hidden sequence is emitted.
- Under the reference Q_p, with the same policy and fresh fair outputs, the probability is exactly 1/2, so the
  intervention alone produces no bias.
- Within the enumerated scope, no admissible witness exists for a passive observer or for the autonomous-hidden
  generators `G_lin` and `G_filt`.
- In this cell, passive m = 2 has no window, and the K = 7 windows of passive m = 3 and linear-filter m = 3 and m = 4
  observers have footprint 7 or 8.
- The result is therefore tied to an active observer and to G_clk's visible-to-hidden backaction.

**Sensitivity analysis (condition (d) read as `signed`, not governing): COUNTEREXAMPLE.** The reported witness has
positive Pr − 1/2 at all four K′. Signed COUNTEREXAMPLEs are a subset of the governing ones, and the run checks this

**Other outcomes** (verdict sections 1–2):

## Scope: what the result does not show

The verdict refutes the universal form for one construction. It does not show any of the following:
- **Other knowledge levels.** No observer is a witness across the family (K0).
- **Other observer or generator classes.** It shows nothing for passive observers or for autonomous generators
  (`G_lin`, `G_filt`).
- **Full OI admissibility of the generator.** Only T-level (C1) is checked. C2–C4 are not, so it is not shown that
  G_clk(z⁵+z²+1) is an admissible OI realization in the full sense.
- **Other resource models.** Admissibility holds with the footprint exactly at θ = n+1 = 6 (memory 2, clock 3,
  output 1), with the 31 table bits held in the dynamics and not charged.
  - If those bits were charged as observer memory, the witness would lie outside θ.
  - For comparison, `Main.md:560` places a protocol table in a read-only program register of the realization's hidden
    sector.
  - θ = n is not tested as a decision rule (A1).
- **Larger n or K.** It shows no predictability beyond K = 7 within a bounded footprint, and makes no asymptotic
  statement.
- **The actual world.** It says nothing about the realization of the actual world, nor about the 10^-32 statement
  (`ch18-beyond.md:56–58`).
- **Security.** No cryptographic, circuit-security or distinguishing-only claim is made.
- **Quantum theory.** No claim is made about quantum theory or its reconstruction.

## Literature

- **The phenomenon is probably known in kind.**
  - Clock-controlled and self-clocked LFSRs are a studied class in stream-cipher cryptanalysis.
  - Rueppel's self-decimated LFSR (Eurocrypt '87), whose own output selects a clocking step of 1 or 2, is essentially
    G_clk's clocking.
  - Agievich–Solovey (arXiv math/0505660, read in full) confirms that construction and Rueppel's period result. It does
    not address prediction.
  - Any claim that the literature covers this predictability therefore rests on references not read here.
- **No novelty is claimed.** No candidate-NEW tag is assigned. None should be assigned for the n = 5 `G_clk` `emb_m2`
  horizons before Rueppel 1987 and Gollmann–Chambers 1989 are read.
- **The COVERED-literature tag (§6 item 5) cannot be assigned mechanically.**
  - RSV, as stated in its abstract (the only part read), treats oblivious read-once permutation branching programs,
    that is, passive tests.
  - AGHP and BDVY were not read. On the reviewer's understanding, not reading, they treat passive tests and small-bias
    inputs.
  - On that basis, none of the citations the plan admits covers an adaptive observer.
  - Whether to extend the admissible list is an owner decision. Tags bear on no verdict.
- **Unread:** Rueppel 1987, Gollmann–Chambers 1989, Meier–Staffelbach 1989, AGHP and BDVY.
