**Reduction candidates (two).**

1. **R-U.** In the already studied fixed-setting U1 subclass of the exact modular-linear rule, can an exact decoder of the previous message using address plus bare values be replaced by one using only the address? **Decision rules.** A reduction earns JUSTIFIED only in the direction whose proof uses the fully stated antecedent. An inherited proof is credited as inherited. An empirical or unproved link is OPEN. An antecedent equivalent to its target voids the candidate. A countercontrol must keep the other named hypotheses and exhibit an actual target difference/failure. An unreached experiment or advertised check is insufficient. If an assumption changes unnoticed, the outcome is INCONCLUSIVE. No other reduction or necessity candidate will be introduced.
