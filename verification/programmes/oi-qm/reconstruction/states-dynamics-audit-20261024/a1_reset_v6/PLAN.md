## Fixed audit boundary and decision rule

1. Write the exact hidden state, preparation and measurement/rotation maps.
   Distinguish continuously supplied stochastic forcing, initially sampled
   vectors, active-index changes, record bits and retained reversible workspace.
2. Compare the first measurement, one subsequent measurement and longer
   records under repeated nonparallel axes. Use one common incoming ensemble
   and deterministic setting choices, with adaptive controls where informative.
3. A supplied-resource positive result requires a written conditional-law
   argument after every complete branch, not only pairwise agreement. If
   previously sampled vectors cannot be reused with the required branch law,
   give a concrete complete-record discrepancy and restrict the conclusion
   to that fixed-vector extension. Do not infer a no-go for OI or for a
   stochastic/noise-renewing variant.
4. For any successful resource repair, list all original-time fresh sources,
   retained garbage, setting/clock primitives and forbidden extra access.
   A generic reversible dilation remains distinct from native compilation.

## Controls and evidence

- Re-derive two-time quantum probabilities independently from the supplied
  hidden update, using exact hemisphere/cap geometry or symbolic integration.
- Compare complete record probabilities with independent rational qubit
  projector/matrix or Markov-chain probabilities. Keep zero-mass branches.
- Include a control detecting absent state update and a control detecting
  re-use versus independent renewal of the hidden vector resource.
- Check rotations and inverse/algebra identities exactly at rational witness
  vectors; no floating-point identity is treated as an exact certificate.
- Bounded numerical or quadrature diagnostics, if needed, are labelled as
  such and never establish a universal claim.
- Write a deterministic standard-library checker, structured result.json,
  provenance pins and SHA256SUMS. Normal and -O runs must match retained output.
