## 4. Qualification test Q0 (owner's condition)

An exit qualifies iff it is either:
- **(G)** generated by the native dynamics from a state or law that itself qualifies; or
- **(S)** selected by a principle stated independently of the gaps, with its free choices fixed by
  something other than the gaps.

Mathematical existence and convenience as an initial condition do not qualify. An exit that adds no
premise (a representation choice only) passes Q0 vacuously; it then counts as inside 𝒞, not as an
exit.

## 5. Decision rule (applied per cell, in this order)

1. **N/A** if fixed as such in §3.
2. **BLOCKED** if an impossibility result, cited or written in the report as P-here, covers
   (x, g) within its stated scope.
3. **ASSUMES** if g enters x's statement, or x fails Q0, or x fails the tuning test. The tuning test
   is failed if some admissible value of x's free parameter yields ¬g.
4. **RESOLVES** if a written proof (paper; kernel where cited) derives g from x and the stated
   posits.
5. **OPEN** otherwise, with the step named.

**Outcomes.**
- **A:** some cell is RESOLVES.
- **B:** every non-N/A cell is BLOCKED or ASSUMES.
- **C:** otherwise.

The verdict text is generated from the cells. A verdict is void if any control fails.

**Covered class.** The covered class is the exits x4 and x5 at odd prime q, under:
- the native linear rule (A5, second-order form);
- the Main Definition;
- full translation invariance.

Any cell whose cited obstruction holds only at odd q is reported with q = 2 separately, as outside
the covered class, with its open step named.
