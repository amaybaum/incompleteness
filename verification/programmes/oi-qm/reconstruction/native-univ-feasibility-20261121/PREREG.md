## What is checked

One structural lemma, stated and proved in `NOTE.md` §3.1 [W]: on `ℤ^d` (or an even torus), any
second-order rule `x(t+1) = F(x(t)) − x(t−1) mod q` whose `F_i` reads only the nearest neighbours
of `i` and not `i` itself (Main ledger (x) and (xi), second clause) splits into two independent
components, and each component is the *staggered* rule on one configuration `y : ℤ^d → ℤ/q`:
at alternate half-steps one sublattice is updated by `y(i) ← F_i(y|N(i)) − y(i)` while the other
is held. Each half-step is an involution.

The checks are exact (integer arithmetic) and bounded. They test the lemma on sampled instances;
they do not prove it, and they decide no universality question.

| Id | Test | Instances |
|---|---|---|
| C1 | Second-order run of the rounded rule `R_q` equals the two staggered runs, site by site, at every tick | `q ∈ {2, 3, 64, 2^16}`, `d ∈ {1, 2, 3}`, even torus sides (`16`, `8`, `6`), 3 seeds each, 24 ticks |
| C2 | Each staggered half-step applied twice is the identity | same instances, every tick |
| C3 | Countercontrol: a rule with a self-term, `F_i = ⌊(Σ_nn x + x_i + 1)/3⌋`, run through the same comparison | same instances |
| C4 | Countercontrol: odd torus side (`d = 1`, side 15), where the lattice is not bipartite, `R_q` through the same comparison | `q ∈ {3, 2^16}`, 3 seeds |
| C5 | The `q = 2`, `d = 3` member: `⌊(s+1)/3⌋ mod 2` for `s = 0,…,6` equals the indicator of `{2, 3, 4}` | exhaustive |

## Decision rule (fixed now)

- The controls are green iff C3 *fails* the comparison on at least one instance of every `(q, d)`
  pair, C4 fails on at least one instance per `q`, and the script itself raises no error.
- If the controls are green: the lemma is reported as "consistent with exact runs on the sampled
  instances" iff C1 and C2 hold on every instance; otherwise as "contradicted by instance …", and
  NOTE §3.1 is withdrawn.
- If a control is not green: no verdict is printed for C1/C2; the output says which control failed.
- C5 is reported as computed.
- The verdict line is generated by the script from these measurements.

## Not run locally

Anything beyond these seconds-long checks (rule-class censuses, glider or collision searches) is
proposed in `NOTE.md` §5 as a plan, not run (§A.40).
