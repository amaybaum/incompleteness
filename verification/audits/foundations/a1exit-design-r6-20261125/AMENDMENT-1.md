- Not adopted from the proposed B4 text: a reserved side-change class `admitted-record` classifying records and review records in a reconciliation directory on `M`. A class record that is not itself on that `M` (one frozen with the plan, or one the post-freeze route admits) already pins such files by blob without a hash cycle (R6.TREE.5), so the class would widen the tool without need (owner direction: "We should avoid further expansion of the verification tool when a simpler solution exists.").
