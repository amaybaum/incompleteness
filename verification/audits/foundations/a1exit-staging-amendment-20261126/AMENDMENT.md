## 3. Make the configuration review binding acyclic

Replace the last configuration widening placement sentence of R6.RECON.31 and align R6.CFG.4's `records` entry and R6.REC.16's pin-table admission rule. The configuration lists other admission records and their reviews. Its own ordinary and widening reviews are furnished by the exact `F` `PREREG.md` Record pins table beside the configuration. The table pins the configuration and the exact review file bytes by path, each independent of the others' table entries. The ordinary review names the exact new configuration path and digest. Whenever R6.CFG.7 requires a widening review, the separate eligible reviewer names that same exact new configuration and the exact old configuration in `replaces`. Both review kinds are selected from pin-table members by schema and exact reference. A missing required review, duplicate review of the same kind, wrong binding or invalid review refuses admission. The config JSON has neither an own-review reference in `records` nor a `widening_review` key. This replaces the circular placement only for the configuration's own reviews. Other record reviews keep their existing reviewed-blob chain and exact placement.

Construct the bytes in dependency order. Independent custody and tool input bytes precede class and allow records. Their reviews and the transition descriptor depend on those records. Configuration bytes pin their own inputs, including the active record references as required, and precede the configuration's own reviews. The external pin table depends on the configuration, reviews and descriptor. No object embeds the identity of the final freeze that would contain it. The configuration and its own review files stay outside the class-pinned tool-landing paths. K1-GRAPH must reject both the direct config-own-widening self-cycle and an indirect cycle through a class pin, review or descriptor. The activated plan directory, `Dir2`–`Dir5`, exact R6.CFG.3 supersession and R6.REC.18 tool/workflow pins all remain required. No changed proof or configuration can reuse an old review by digest alone.
