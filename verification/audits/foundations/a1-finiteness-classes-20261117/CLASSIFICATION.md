## Definitions and table grammar

**F1** means each spatial site takes values in a finite alphabet. **F2** means the complete spatial site set is finite. Under the declared fixed site-product construction **F1 + F2 ⇒ A1** ([SubstratumInterfaceAudit.a1_of_finite](https://github.com/amaybaum/incompleteness/blob/411c838889ce79e78f9061b396b9af3d02c695e1/verification/lean-mathlib/OIBridge/SubstratumInterfaceAudit.lean#L108-L111)); this is a **one-way implication only**. Neither alone establishes A1, and no cited result derives F1 or F2 from A1. **F3** means finite visible distinctions on a specified finite observation horizon, not a bound on hidden states. **F4** means a finite backward causal dependence region for a finite readout W and finite K under a finite-range or locally finite-input update. F4 is *not* an autonomous finite closed system; equality of statistical outputs with another model also requires matched initial joint law (including correlations) on that cone. **A1** is total finiteness of all complete configurations, a separate open posit, not a consequence of finite access, cone locality or boundary entropy. A1 alone says nothing about bijectivity.

In axis columns **R** = required by the **cited proof as scoped** (not logically necessary under all other methods), **S** = supplied *in the stated model* but unnecessary to the local implication, **C** = sufficient only with the named additional premises, **N** = neither supplied nor required by the stated implication (or explicitly not implied), **U** = not audited. Source-paper ladder labels F1/F2/F11 are independent of THESE F1–F4 axes. ## Dependency graph — only forward arrows

- F1 + F2 + fixed spatial product => A1. A1 + full bijection => one common finite microscopic order; with earlier overlap and shared rooted prior => recurrence-scale P-indivisibility. No accessible time bound follows.
- F3 + finite K + stochastic joint law => one constructed finite D(K) => fixed-basis representation. **Not** a selected physical same-carrier family for all K, or coherent instruments.
- Finite-range update + finite W + finite K + matched initial cone law => F4: same window observations. **Not** a closed patch, A1, all-time equality, global recurrence or a common rooted return.
- Genuine C4 history readback => positive *multi-time conditional memory*. Genuine C4r/C4e rooted revival => *rooted P-indivisibility*. Neither premise follows from finite access alone, and history memory does not automatically yield rooted revival.
- Invariant normalized measure => Poincare pointwise recurrence (almost everywhere). **Not** common rooted identity return. F11's synchronized near-return bound is an independent sufficient condition.
- Local six-link + independently supplied H-link/H-cust/condensate => conditional local stabilizer; chosen charged action => conditional group/charge equations. **Not** a native physical observer, Yang–Mills/QCD, or complete quantum apparatus.

## The NR-1 causal-cone / wraparound distinction (non-negotiable)
